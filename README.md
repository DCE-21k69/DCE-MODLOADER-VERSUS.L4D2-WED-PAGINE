# 🌐 DCE MODS LOADER — Página Web Oficial de Presentación

Este repositorio contiene el código fuente de la página web oficial de presentación, descargas y documentación interactiva para **DCE Mods Loader [Versus Suite]** para Left 4 Dead 2.

Desarrollado por **DCE STUDIOS** | [🌐 Visitar Web Principal](https://dcegaming.netlify.app/)

---

## 🚀 Cómo Publicar en GitHub Pages

1. Ve a los **Ajustes (Settings)** de este repositorio en GitHub.
2. En la barra lateral izquierda, selecciona la pestaña **Pages**.
3. En la sección **Build and deployment > Source**, elige **Deploy from a branch**.
4. En **Branch**, selecciona la rama `main` y la carpeta `/ (root)`.
5. Haz clic en **Save**. En 1 minuto tu página estará en línea en:
   `https://dce-21k69.github.io/DCE-MODLOADER-VERSUS.L4D2-WED-PAGINE/`

## 🛠️ Tecnologías Utilizadas

* **HTML5 Semántico**: Optimizado con etiquetas OpenGraph para compartir en Discord, WhatsApp, Twitter y redes sociales.
* **CSS3 Moderno**: Diseño Dark Glassmorphism, paleta de colores oficial Fuego & Obsidiana (`#FF6A00`), variables CSS y 100% responsivo para celulares, tablets y PC.
* **Canvas Particles Engine**: Brasas de fuego flotantes animadas con bajo consumo de CPU/GPU.
* **Vanilla JavaScript ES6+**: 3D tilt interactivo, selector de pestañas para tutoriales, acordión para preguntas frecuentes y botones con copiado al portapapeles.
